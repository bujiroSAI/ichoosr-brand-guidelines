Section 06

Brand Values (6 Core)

6項目は維持。ピラミッドからフラット並びへ。3グループ（最優先軸／ブランド固有／事業価値）で運用する。

① 原文（本国オリジナル）
[EN] Brand Values 6項目（0.2 Page 6, Page 10）

Sympathetic / Dedicated / Supportive / Knowledgeable / Trustworthy / Collaborative

[EN] Pyramid Structure

Sympathetic (top) → Dedicated, Supportive (middle) → Knowledgeable, Trustworthy, Collaborative (bottom)

[JP] 本国訳

共感的（頂点）／献身的・支援的（中段）／知識豊富・信頼できる・協働的（下段）

② 問題点

6項目の内容自体は問題ない（WS01でも調整必要度が最低の2.40）。ただし以下の論点：

  • 本国ピラミッドの上位（Sympathetic）が、日本市場の事業実態（太陽光中心）と合致しない
  • 6項目を毎回全部出すと、何が大事か伝わらない（「6つで多い／使われていない」WS01）
  • 2（献身的）・6（協力的）は iChoosr のブランド固有だが、共同購入の主語で語ると意味がぼやける
  • 3（知的好奇心）と 6（協力的）はほぼ同質との指摘
③ 修正のポイント

翻訳の理由

  • 6項目の和訳は維持（変更すると本国整合が崩れる）
  • 定義文・実例文は日本語として自然なトーンに調整

構造の理由

  • ピラミッドからフラット並びへ変更（5/19合意）
  • 「信頼できる（Trustworthy）」を最優先軸に
  • 6項目を 3グループに分けて運用：最優先軸／ブランド固有／事業価値
  • 場面ごとに2-3項目を選んで使う（毎回全部出さない）
WS01 ポストイットより 「信頼性は事業の基盤」「協力的にも支持が集まった」「6つで多い／使われていない」
5/19ミニWS — 広瀬 「2（献身的）と6（協力的）はiChoosrのブランドとしては意味があるが、共同購入の主語で考えるとピンとこない」
④ 日本版 最終案

3グループ × 6項目（フラット構造）

TOP PRIORITY — 最優先軸

信頼できる（Trustworthy）

明確に伝え、約束を守る。誠実さと透明性に誇りを持つ。

BRAND-SPECIFIC — ブランド固有

協働的（Collaborative）／献身的（Dedicated）

参加者・パートナー・自治体と対等に関わり、ぶれずに取り組む。

BUSINESS VALUE — 共同購入の事業価値

共感的（Sympathetic）／支援的（Supportive）／知識豊富（Knowledgeable）

生活者の状況を理解し、すべてのステップを支え、率直で徹底した情報を提供する。

運用： 6項目を毎回全部出さない。自治体接点では「協働的・献身的」を、消費者接点では「信頼・知識豊富」を前面に出す、など場面で重みづけを変える。
