Section 06

Brand Values (6 Core)

6項目は維持。ピラミッドからフラット並びへ。3グループ（最優先軸／ブランド固有／事業価値）で運用する。

① 原文（本国オリジナル）
[EN] Brand Values 6項目（0.2 Page 6, Page 10）

Sympathetic / Dedicated / Supportive / Knowledgeable / Trustworthy / Collaborative

[EN] Pyramid Structure

Sympathetic (top) → Dedicated, Supportive (middle) → Knowledgeable, Trustworthy, Collaborative (bottom)

[JP] 本国訳

共感的（頂点）／献身的・支援的（中段）／知識豊富・信頼できる・協働的（下段）

② 問題点

6項目自体はWS01で 共感度3.50／実践度3.30／調整必要度2.40（5セクション中最高スコア）と評価。ただし「6つで多い」「使われていない」との指摘、本国ピラミッドの上位（Sympathetic）が日本の事業実態（太陽光中心）と合致しない問題、項目の役割の混在が論点。

③ 議論の方針
Structure｜構造の方針

ピラミッドからフラット並びへ

本国ピラミッドの上位が日本の事業実態と合致しないため、フラット並びに変更（5/19合意）。「信頼できる」を最優先軸に置く。

Translation｜翻訳の方針

6項目の和訳は維持

本国整合のため、6項目の名称（共感的／献身的／支援的／知識豊富／信頼できる／協働的）は変更しない。定義文・実例文の和文トーンのみ調整。

Operation｜運用の方針

3グループに分けて場面別に使う

最優先軸（信頼できる）／ブランド固有（献身的・協働的）／事業価値（共感的・支援的・知識豊富）の3グループに分け、場面に応じて2-3項目を選ぶ。毎回6項目すべてを出さない。

④ 日本版 最終案

3グループ × 6項目（フラット構造）

TOP PRIORITY — 最優先軸

信頼できる（Trustworthy）

明確に伝え、約束を守る。誠実さと透明性に誇りを持つ。

BRAND-SPECIFIC — ブランド固有（iChoosrの主語）

協働的（Collaborative）／献身的（Dedicated）

参加者・パートナー・自治体と対等に関わり、ぶれずに取り組む。

BUSINESS VALUE — 共同購入の事業価値

共感的（Sympathetic）／支援的（Supportive）／知識豊富（Knowledgeable）

生活者の状況を理解し、すべてのステップを支え、率直で徹底した情報を提供する。

運用： 6項目を毎回全部出さない。自治体接点では「協働的・献身的」を、消費者接点では「信頼・知識豊富」を前面に出す、など場面で重みづけを変える。
