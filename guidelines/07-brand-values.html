Section 07

Brand Values (6 Core)

ピラミッドからフラット並びへ。「信頼できる」を最上位、共同購入の主語とブランド固有の主語を分けて運用する。

日本版 確定構造 — 3グループ × 6項目

最優先軸

Top Priority
信頼できる
Trustworthy
私たちは、明確に伝え、約束を守ります。誠実であること、透明であることに、誇りを持っています。

「価格・保証・条件は、事前に開示します。隠して有利になるものは、ひとつもありません。」

Brand-specific
協働的
Collaborative
共に力を合わせることで、より多くを成し遂げられると信じています。参加者やパートナーと対等な関係で関わります。

「私たちのサービスは、自治体と一緒に、あなたの利益を考えながら進めています。」
Brand-specific
献身的
Dedicated

「私たちは、参加するすべての人にとって、賢く、シンプルな解決策を育てていきます。」

Business value
共感的
Sympathetic

支援的

知識豊富
Knowledgeable

なぜそうしたか — 修正のポイント

POINT 01

ピラミッドからフラットへ

本国のピラミッド構造は、日本市場の事業実態（太陽光中心）と上位要素が合致しない（5/19合意）。日本版はフラット並びを採用。

POINT 02

「信頼できる」を最優先軸に

WS全体を貫く「信頼・安心」の軸を、6 Core Values の最上位に明示する。

POINT 03

主語を3グループに分ける

「献身的」「協働的」は iChoosr というブランド固有の価値。「共感的・支援的・知識豊富」は共同購入そのものの事業価値。混在を避ける。

POINT 04

場面ごとに重みづけ

6項目を毎回全部出さない。自治体接点では「協働的・献身的」を前面に。消費者接点では「信頼・知識豊富」を前面に。

運用ルール： 3（知的好奇心）と 6（協力的）が両方含まれる場面は、よりブランド寄りの6を選ぶ。事業共通の場面は3を選ぶ。詳細は Operations / 運用方法論。
